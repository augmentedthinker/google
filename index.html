Google / Gemini Workspace

Google Repo

This is a deliberately simple GitHub Pages site for experiments made with Google Gemini models. Treat it as a small public workspace: artifacts go in one place, session notes go in another, and markdown files explain how the repo is meant to be used.

What this site is for

The goal is clarity over complexity. Gemini agents using this repo should be able to quickly understand what exists, where new work belongs, and how to add future experiments without needing a large framework.

Current model focus

  • google/gemini-2.5-flash
  • google/gemini-2.5-pro
  • google/gemini-3.1-flash-lite-preview
Artifacts Standalone HTML experiments, demos, and generated pages. Session Notes Short records of what happened during work sessions. Markdowns README, repo reference, and workspace instruction files.
