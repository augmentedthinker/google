# Google Repo Reference Guide

This repository is the simple public workspace for Google/Gemini experiments.

Live site: <https://augmentedthinker.github.io/google/>

## Main Purpose

Use this repo to collect lightweight Gemini/OpenClaw outputs in a structure that small models can understand.

## Main Pages

- `index.html` — homepage and orientation page
- `artifacts.html` — browser-viewable generated artifacts
- `session-notes.html` — continuity notes from work sessions
- `markdowns.html` — links to markdown and workspace instruction files

## Add New Artifacts

1. Create a standalone `.html` file.
2. Add it to `artifacts.html`.
3. Put newest links near the top.
4. Verify the link works.

## Add New Session Notes

1. Create `session-note-N.html`.
2. Summarize what changed, why, and what comes next.
3. Add it to `session-notes.html`.

## Keep It Simple

No build system. No backend. No unnecessary dependencies. GitHub Pages serves the static files directly.
